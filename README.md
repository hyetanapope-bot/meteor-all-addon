# AllAddons ☄️

Один аддон для **Meteor Client 26.3** (Minecraft 26.3, JDK 25), который собирает самые полезные
фичи популярных аддонов сообщества в одном месте — вместо десяти jar-файлов в папке `mods`.

* **17 модулей** в собственной категории `AllAddons` в ClickGUI.
* **1 HUD-элемент** — счётчик предметов в инвентаре.
* Ничего не требует: без миксинов, без зависимостей кроме самого Meteor.
* Проверяется скриптом `tools/verify.py` — сверяет импорты и версии с исходниками Meteor.

> English version: [README.en.md](README.en.md)

## Установка

1. Поставьте **Meteor Client 26.3** (Fabric 26.3 + Fabric Loader ≥ 0.19.5, JDK 25).
2. Скачайте `all-addons-1.0.0.jar` из [Releases](../../releases) или соберите сами (ниже).
3. Положите jar в `.minecraft/mods`.
4. Запустите игру — модули появятся в ClickGUI в категории **AllAddons**, HUD-элемент — в редакторе HUD.

## Сборка

```bash
./gradlew build
# готовый jar: build/libs/all-addons-1.0.0.jar
```

Зависимости тянутся из Maven Meteor (`maven.meteordev.org`) и Maven Central.

### Проверка без сборки

```bash
python3 tools/verify.py --meteor ../meteor-client
```

Скрипт не требует JDK: он проверяет структуру Java-файлов, существование каждого
`meteordevelopment.meteorclient.*` импорта и его членов, соответствие `fabric.mod.json`,
`libs.versions.toml` и `AllAddons.VERSION`, а также уникальность имён модулей.
CI гоняет его на каждый push (`.github/workflows/verify.yml`).

## Важные оговорки

* **`auto-login`** хранит пароль в открытом виде в конфиге Meteor. Не используйте на серверах,
  где этот пароль совпадает с чем-то важным.
* **`chat-encryption`** — это XOR + Base64, а не криптография. Защищает от случайных читателей
  в логах чата, но не от тех, у кого есть аддон и ключ.
* **`skeleton-esp`** рисует приблизительную фигуру по хитбоксу: поза модели (присед, езда, взмах)
  не считывается.
* **`packet-delay`** всегда пропускает keep-alive/pong/`CustomPayload`, иначе сервер выкинет вас
  по таймауту.
* Модули, которые двигают вас (`auto-center`, `wind-charge-jump`) и взаимодействуют с миром
  (`auto-doors`, `auto-dirt-path`), могут не понравиться анти-читу сервера. Это ваша ответственность.

## Структура проекта

```
src/main/java/dev/alladdon/
├── AllAddons.java              # точка входа, категория, регистрация HUD
├── hud/ItemCounterHud.java
└── modules/{render,misc,player,movement,world}/
tools/
├── verify.py                   # статическая проверка против исходников Meteor
└── make_icon.py                # генерация иконки без внешних библиотек
docs/
├── FEATURES.md                 # подробно про каждый модуль и его настройки
└── API-NOTES.md                # заметки по API Meteor 26.3, на которые опирается код
```

Классы модулей Meteor находит сам (сканирует пакет `dev.alladdon`), поэтому регистрировать
каждый модуль вручную не нужно — достаточно вызвать `super(AllAddons.CATEGORY, ...)`.
