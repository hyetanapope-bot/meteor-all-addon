# Modules

Every module lives in the `AllAddons` ClickGUI category. Defaults are chosen to be safe on a normal
server; anything that interacts with the world is off until you enable it.

---

## Render

### `chunk-borders`

Draws the chunk grid around you — the cheapest way to see where chunk borders are before you mine or
build.

| Setting | Default | Meaning |
| --- | --- | --- |
| `radius` | 2 | How many chunks in each direction are outlined |
| `height` | 16 | How far above/below you the vertical lines extend |
| `floor-grid` | true | Also draw a flat grid at your feet height |
| `line-color` | purple, 200 alpha | Colour of the lines |

Lines are clamped to the world height, so nothing is drawn outside the build limit.

### `spawner-esp`

Scans blocks around you each tick and highlights mob spawners. Meteor's `storage-esp` does not cover
spawners and `block-esp` needs per-block configuration, so this is a one-click alternative.

| Setting | Default | Meaning |
| --- | --- | --- |
| `horizontal-radius` | 16 | Horizontal scan radius |
| `vertical-radius` | 8 | Vertical scan radius |
| `shape-mode` | Both | Fill, lines or both |
| `side-color` / `line-color` | purple | Colours |
| `tracers` | false | Draw a line from your eyes to each spawner |

### `tnt-fuse-esp`

Highlights primed TNT and interpolates between `safe-color` and `danger-color` as the 80-tick fuse
burns down, so you can tell at a glance how long you have.

| Setting | Default |
| --- | --- |
| `range` | 32 |
| `shape-mode` | Both |
| `safe-color` | purple |
| `danger-color` | red |

### `new-chunks`

A chunk the client receives for the first time in a session is almost always freshly generated by
the server — that is how new bases, tunnels and mining operations are found on anarchy servers.

| Setting | Default | Meaning |
| --- | --- | --- |
| `lifetime` | 60 | Seconds a highlighted chunk stays marked |
| `radius` | 12 | Only chunks within this many chunks are drawn |
| `ignore-first-ticks` | 100 | Skips the chunks of the world you spawned into |
| `line-color` | amber | Outline colour |

The mark fades out over its lifetime.

### `sound-locator`

Marks the position of nearby sounds: footsteps, mining, a chest opening behind a wall.

| Setting | Default | Meaning |
| --- | --- | --- |
| `range` | 24 | Ignore sounds further away |
| `lifetime` | 3 s | How long a marker stays |
| `ignore-own` | true | Skip sounds basically at your own position |
| `ignore-ambient` | true | Skip music/ambience by registry path |
| `size` | 0.4 | Marker size |
| `shape-mode` / colours | Lines / amber | Appearance |

Duplicate sounds at (nearly) the same spot within 250 ms are merged.

### `skeleton-esp`

Draws a stick figure inside nearby players.

| Setting | Default |
| --- | --- |
| `range` | 48 |
| `color` | red, 220 alpha |

The figure is derived from the standing hitbox, so it does not follow sneaking, riding or swinging
poses — it is an indicator, not a model reconstruction.

### `lava-warning`

| Setting | Default |
| --- | --- |
| `radius` | 3 |
| `cooldown` | 5 s |
| `fire` | true |

## Movement

### `auto-center`

Slides you into the middle of the block under you. Being exactly on a block centre matters for hole
digging, crystal placement and most highway bots.

| Setting | Default | Meaning |
| --- | --- | --- |
| `speed` | 0.15 blocks/tick | Sliding speed, never overshoots |
| `tolerance` | 0.05 | Distance that counts as centred |
| `disable-when-centered` | true | Turns itself off once done |

Enable it with a keybind; with `disable-when-centered` it is a one-shot "centre me" button.

### `wind-charge-jump`

A wind charge used while looking straight down launches you upward. This module aims down, swaps the
charge into your hand, clicks, and swaps back — four ticks of work behind one keybind.

| Setting | Default |
| --- | --- |
| `rotation-priority` | 100 |

It disables itself if no wind charge is in the hotbar.

## World

### `auto-doors`

Opens doors when you get close and (optionally) closes them once you walk away. Iron doors and
powered doors are skipped, since those need redstone.

| Setting | Default | Meaning |
| --- | --- | --- |
| `open-range` | 2.5 | Open doors closer than this |
| `close-range` | 3.5 | Close open doors further than this |
| `delay` | 4 ticks | Gap between interactions |
| `close` | true | Close doors behind you |

Each door has a 500 ms cooldown so the module cannot spam interactions.

### `auto-dirt-path`

Finds grass, dirt, coarse dirt, podzol, mycelium or rooted dirt around you and uses a shovel on it.

| Setting | Default |
| --- | --- |
| `radius` | 3 |
| `delay` | 4 ticks |

Requires a shovel in the hotbar; the module turns itself off if there is none.

## Misc

### `ad-blocker`

Cancels incoming chat messages that contain any keyword from the list. Purely client-side substring
matching — nothing leaves your game.

| Setting | Default |
| --- | --- |
| `keywords` | `discord.gg`, `twitch.tv/`, `buy now`, `/shop`, … |
| `notify` | false |

The number of hidden messages is shown as the module's info string.

### `chat-encryption`

XOR + Base64 around your chat, so server logs and bystanders see noise instead of your message.

| Setting | Default | Meaning |
| --- | --- | --- |
| `key` | `change-me` | Shared secret; both sides need the same one |
| `encrypt-outgoing` | true | Commands are never encrypted |
| `decrypt-incoming` | true | Decodes messages carrying the `[#enc]` marker |

Messages that would exceed the 256-character chat limit after encryption are sent unencrypted, with a
warning. This is obfuscation, not cryptography.

### `anti-vanish`

Staff with `/vanish` disappear from the world but stay in the tab list. This module remembers where
it last saw every player and reports when someone within range disappears while still being listed,
including their last coordinates.

| Setting | Default |
| --- | --- |
| `check-interval` | 20 ticks |
| `range` | 64 |

Players that were never near you are not reported, which avoids the false positives of naive
tab-list-versus-world comparisons.

### `coord-logger`

Writes the coordinates of players you see, to chat and/or to
`<game dir>/meteor-client/coord-logger.txt`.

| Setting | Default | Meaning |
| --- | --- | --- |
| `range` | 64 | Distance limit |
| `cooldown` | 30 s | Per-player logging cooldown |
| `chat` | true | Print to chat |
| `file` | true | Append to the log file |

### `packet-delay`

Holds outgoing packets for a fixed time. Useful for reproducing a laggy connection or delaying a
burst of clicks.

| Setting | Default | Meaning |
| --- | --- | --- |
| `delay` | 100 ms | Hold time |
| `max-queued` | 64 | When exceeded, the oldest packet is released early |

Keep-alive, pong, client-information and custom-payload packets are never delayed, otherwise the
server drops you. The queue is flushed when the module is turned off.

### `auto-login`

Sends `/login <password>` a configurable number of ticks after joining, optionally followed by a
`/register` command.

| Setting | Default | Meaning |
| --- | --- | --- |
| `password` | empty | Stored in plain text in your Meteor config |
| `command` | `login` | Login command name |
| `register` | false | Also send the registration command |
| `register-command` | `register` | Command name used for registration |
| `delay` | 60 ticks | Wait after joining before sending |

It warns and does nothing when no password is set.

## HUD

### `item-counter`

Counts everything in your inventory (hotbar, main inventory, offhand) and lists the item types you
carry most of.

| Setting | Default | Meaning |
| --- | --- | --- |
| `sort` | Count | Sort by count or by name |
| `max-lines` | 8 | Maximum item types shown |
| `show-total` | false | Extra line with the total amount |
| `shadow` | true | Text shadow |
| `text-color` / `count-color` | white / purple | Colours |
| `background` / `background-color` | off | Background box |

In the HUD editor it renders a placeholder list so you can position it before joining a world.
